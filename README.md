# CG 2025/2026

Coursework for **CG (Computação Gráfica / Computer Graphics)** at FEUP, L.EIC 3rd year, 2nd semester. Built in JavaScript with WebGL and the [WebCGF](lib/CGF.js) framework.

- **tp1 – tp5**: weekly lab assignments, from basic geometry and transformations to lighting, materials, textures and GLSL shaders. Each folder has a README with our notes.
- **project**: the final project, an interactive prairie survival game with an animated sky, heightmap terrain, a drivable wagon, a barn and custom shaders. See the [project README](project/README.md) for features and screenshots.
- **lib**: the WebCGF library and dat.GUI used by every assignment.

To run any of them, serve the repo root with a local web server (e.g. `python3 -m http.server`) and open the `index.html` in the folder you want.
